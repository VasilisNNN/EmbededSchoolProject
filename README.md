# Beetroot EMB 4

Навчальний проєкт для STM32F411CEU6 (плата Black Pill). Активний приклад демонструє універсальний циклічний логер: записи по 32 байти зберігаються в EEPROM AT24C32, відновлюються після перезапуску та виводяться через `printf` у USB CDC.

## Що демонструє проєкт

- EEPROM зберігає 128 вирівняних сторінок по 32 байти; при заповненні нові записи циклічно перезаписують найстаріші.
- Під час запуску логер перевіряє зв'язок з EEPROM, сканує всі сторінки, перевіряє CRC і відновлює номер та адресу наступного запису.
- Тестова програма друкує кількість і діапазон збережених логів, демонструє читання діапазону, всіх логів та окремого останнього логу. Далі вона щосекунди додає показники BME280, читає їх назад і виводить через `printf`.
- Запис має текстовий вигляд `#015|Info: logger started     |ABCD`: три цифри номера, до 22 символів повідомлення і CRC-16. Нумерація циклічна `000..999`; CRC допомагає відкидати порожні, пошкоджені та незавершені сторінки.

Модулі `i2c` та `oled` використовують STM32 HAL. `oled` передає команди і framebuffer через наявний I2C API. ESP-IDF-компонент `k0i05/esp_ssd1306` напряму не підходить до цього проєкту, тому драйвер повторює його можливості та шрифти (MIT) під HAL; окрему залежність додавати не потрібно.

## Апаратна конфігурація

- I2C: I2C1, master, PB6 (SCL), PB7 (SDA), 100 кГц
- MCU: STM32F411CEUx
- Framework: STM32Cube HAL
- Збірка та завантаження: PlatformIO, ST-Link

### Підключення EEPROM AT24C32

| AT24C32 | Black Pill |
|---------|------------|
| VCC | 3V3 |
| GND | GND |
| SDA | PB7 (I2C1 SDA) |
| SCL | PB6 (I2C1 SCL) |
| WP | GND (дозволити запис) |
| A0, A1, A2 | GND (I2C адреса `0x50`) |

Перевірте маркування контактів саме вашого EEPROM-модуля. I2C pull-up-и мають підтягувати SDA/SCL до 3,3 В; не використовуйте підтягування до 5 В. Адресу можна змінити на `0x50`–`0x57`, змінивши рівні A0–A2 і параметр `a_pins` у `AT24C32_Init()`.

Під'єднайте Black Pill окремо USB-кабелем із передачею даних для USB CDC-консолі. Вивід `printf` цього прикладу йде через USB CDC, а не через SWD чи USART. Зберіть і завантажте прошивку командами `pio run` та `pio run -t upload`, потім відкрийте USB CDC serial port у терміналі; для перегляду стартових повідомлень відкрийте термінал перед скиданням плати. Якщо AT24C32 або BME280 не відповідає чи I2C ініціалізація завершується помилкою, програма зупиниться з повідомленням про помилку. Під час першого запуску порожня EEPROM буде показана як така; потім програма щосекунди зберігатиме показники BME280. Після перезапуску записи залишаться в EEPROM.

Бібліотеки EEPROM і логера розміщені за шляхами `Inc/at24c32/` + `Src/at24c32/` та `Inc/logger/` + `Src/logger/`. `AT24C32_Read()` і `AT24C32_Write()` працюють із адресами байтів; запис автоматично розбивається на сторінки EEPROM. `Logger::Write()` додає один пронумерований лог; `count()`, `oldest_number()`, `newest_number()`, `Read()`, `read_range()` і `read_all()` надають операції читання. Для `Read()` потрібен текстовий буфер щонайменше `log_text_capacity` байтів. Range є включним та підтримує перехід, наприклад `read_range(998, 2, ...)` читає `998, 999, 000, 001, 002`, якщо ці номери ще збережені. Обидві функції читання діапазону та всіх логів передають записи callback-функції; помилки EEPROM повертаються як `HAL_StatusTypeDef`.

### Завантаження через SWD

Для завантаження прошивки під'єднайте ST-Link до Black Pill:

| ST-Link | Black Pill |
|---------|------------|
| SWDIO | SWDIO (PA13) |
| SWCLK | SWCLK (PA14) |
| GND | GND |
| VTref | 3V3 (опорна напруга цілі) |
| NRST | NRST (необов'язково, рекомендовано для відновлення підключення) |

Під'єднайте ST-Link до комп'ютера USB-кабелем із передачею даних. GND програматора і плати мають бути спільними. Якщо плата вже живиться через USB, не з'єднуйте паралельно вихід живлення ST-Link із платою; під'єднуйте VTref згідно з інструкцією вашого ST-Link. Не подавайте 5 В на контакт 3V3. Для завантаження з Flash встановіть BOOT0 у LOW.

### Підключення OLED SSD1306

Під'єднайте SDA до PB7, SCL до PB6, а також живлення та GND. Драйвер підтримує панелі 128x32, 128x64 та 128x128; приклад налаштований на 128x64 і адресу `0x3C`. Якщо модуль має адресу `0x3D`, вкажіть її в `OLED_SettingsTypeDef.address`.

Усередині STM32 увімкнені слабкі підтягувальні резистори, але для надійної роботи на шині потрібні зовнішні (зазвичай вони вже є на модулі OLED).

### Підключення годинника DS1307

Під'єднайте SDA годинника до PB7, SCL до PB6, а живлення та GND — згідно з вимогами модуля. Годинник і OLED підключаються до однієї I2C-шини: адреси DS1307 (`0x68`) і OLED (`0x3C` або `0x3D`) різні. Для збереження часу після вимкнення живлення встановіть резервну батарейку на модуль.

Переконайтеся, що лінії SDA/SCL не підтягуються до 5 В: входи STM32F411 працюють з логічним рівнем 3,3 В. За потреби використайте перетворювач рівнів або підтягування до 3,3 В. Драйвер DS1307 збережений у репозиторії, але активний SWD demo його не ініціалізує.

### Підключення BME280

Під'єднайте BME280 до тієї самої I2C1-шини: SDA до PB7, SCL до PB6, а живлення та GND — згідно з вимогами модуля. Драйвер автоматично перевіряє адреси `0x76` та `0x77`. Використовуйте BME280 (ідентифікатор чипа `0x60`); BMP280 не має датчика вологості. Перевірте, що модуль сумісний з логічним рівнем 3,3 В. Активний приклад записує показники цього датчика в EEPROM.

## Збірка

```
pio run
pio run -t upload
```

## API модулів

### I2C (`Inc/i2c/i2c.h`)

Усі функції приймають 7-бітну адресу пристрою (без зсуву) і працюють у блокувальному режимі.

| Функція | Призначення |
|---------|-------------|
| `I2C_Init(&hi2c, I2C1, speed_hz)` | Ініціалізація I2C1 (master, 7-бітна адресація, до 400 кГц) |
| `I2C_Probe(&hi2c, addr, timeout)` | Перевірка, чи відповідає пристрій за адресою |
| `I2C_Scan(&hi2c, found, max_found, &count, timeout)` | Пошук усіх пристроїв в діапазоні `0x08`–`0x77`; `count` — загальна кількість знайдених |
| `I2C_ReadRegister(&hi2c, addr, reg, data, size, timeout)` | Читання регістрів з 8-бітною адресою регістра |
| `I2C_Transmit` / `I2C_Receive` | Пряма передача й прийом даних |

### OLED (`Inc/oled/oled.h`)

Драйвер SSD1306 (128x32, 128x64, 128x128) із прихованим дескриптором `OLED_HandleTypeDef *`. Усі функції повертають `HAL_StatusTypeDef`; зображення зберігається у framebuffer, а змінені сторінки одразу передаються на дисплей. Пам'ять під дескриптор і framebuffer береться з купи (`calloc`).

| Функція | Призначення |
|---------|-------------|
| `OLED_Init(&hi2c, &settings, &oled)` | Ініціалізація дисплея на шині I2C; `OLED_SETTINGS_128X64_DEFAULT()` — типові параметри |
| `OLED_Deinit(oled)` | Видалення дисплея, звільнення пам'яті |
| `OLED_Clear(oled)` | Очищення екрана |
| `OLED_DrawPixel` / `OLED_DrawLine` | Піксель, лінія |
| `OLED_DrawCircle` / `OLED_FillCircle` | Коло, залите коло |
| `OLED_DrawRectangle` / `OLED_FillRectangle` | Прямокутник, залитий прямокутник |
| `OLED_SetContrast(oled, 0..255)` | Яскравість |
| `OLED_Power(oled, on)` | Увімкнення / сплячий режим |
| `OLED_Print(oled, row, scale, invert, text)` | Текст шрифтом 8x8 у рядку сторінки (`scale` 1–3: до 16, 8, 5 символів) |
| `OLED_Printf(oled, row, scale, fmt, ...)` | Те саме з форматуванням `printf` (до 32 символів) |
| `OLED_PrintBdf(oled, font, x, y, text)` | Текст BDF-шрифтом (напр. `OLED_BdfFontNenr12_21x26`) у довільній позиції |

Параметри `OLED_SettingsTypeDef`: `address` (0 = `0x3C`), `scl_speed_hz` (0 = залишити поточну швидкість шини; інакше шина переналаштовується, до 400 кГц), `panel`, `flip` (поворот на 180°). У графічних функціях `invert = true` гасить пікселі.

Приклад:

```c
static I2C_HandleTypeDef hi2c1;

I2C_Init(&hi2c1, I2C1, 100000U);

OLED_SettingsTypeDef settings = OLED_SETTINGS_128X64_DEFAULT();
OLED_HandleTypeDef *oled = NULL;

OLED_Init(&hi2c1, &settings, &oled);
OLED_Print(oled, 0, 2, false, "Hello");
OLED_Printf(oled, 4, 1, "T=%d C", 25);
OLED_PrintBdf(oled, OLED_BdfFontNenr12_21x26, 0, 30, "12:34");
`````

### DS1307 (`Inc/ds1307/ds1307.h`)

Драйвер годинника реального часу DS1307 (I2C-адреса `0x68`) із прихованим дескриптором `DS1307_HandleTypeDef *`. Усі функції повертають `HAL_StatusTypeDef`; пам'ять під дескриптор береться з купи (`calloc`). Підтримується рік 2000–2099, `weekday`: 1 = неділя, ..., 7 = субота.

| Функція | Призначення |
| --- | --- |
| `DS1307_Init(&hi2c, &rtc)` | Додає годинник до шини I2C (перевіряє його наявність) |
| `DS1307_Deinit(rtc)` | Видаляє дескриптор; шина залишається відкритою |
| `DS1307_GetDateTime(rtc, &dt)` | Читає дату й час (приймає 12- і 24-годинний формат) |
| `DS1307_SetDateTime(rtc, &dt)` | Перевіряє й записує дату й час, запускає генератор |
| `DS1307_IsRunning(rtc, &running)` | Чи працює генератор (біт CH) |
| `DS1307_SetRunning(rtc, running)` | Зупиняє або запускає генератор |

Приклад:

```c
DS1307_HandleTypeDef *rtc = NULL;
DS1307_DateTimeTypeDef dt = {2026, 10, 11, 1, 12, 30, 0};

DS1307_Init(&hi2c1, &rtc);
DS1307_SetDateTime(rtc, &dt);
DS1307_GetDateTime(rtc, &dt);
```

## Структура

- `Src/app/main_app.cpp` — приклад логування показників BME280, роботи з EEPROM та виводу на OLED/USB CDC
- `Src/i2c/i2c.c`, `Inc/i2c/i2c.h` — I2C-модуль
- `Src/oled/oled.c`, `Inc/oled/oled.h` — драйвер SSD1306
- `Src/oled/oled_font_*.c`, `Inc/oled/oled_font.h` — шрифти 8x8 та BDF (MIT, з esp_ssd1306)
- `Src/ds1307/ds1307.c`, `Inc/ds1307/ds1307.h` — драйвер годинника DS1307
- `Src/main.c` — запуск HAL, системного тактування та периферії
- `Src/stm32f4xx_it.c` — обробники переривань
- `Src/stm32f4xx_hal_msp.c` — низькорівневе налаштування іншої периферії
- `Inc/stm32f4xx_hal_conf.h` — конфігурація HAL (увімкнено I2C)
